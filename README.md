# FacilityERP

FacilityERP is an Integrated Facility Management ERP System.

## Purpose

The system is designed to manage facility operations such as:

- Asset Management
- Maintenance Requests
- Work Orders
- Preventive Maintenance
- Inventory Management
- Vendor Management
- Purchase Management
- Facility Expenses
- Reports and Dashboards
- User Roles and Permissions
